# Тетрис в терминале Linux

В игре реализованы основные механики тетриса; падение фигур, поворот, движение влево/вправо, удаление заполненных линий, подсчет очков и увеличение скорости с уровнем.

Для обработки ввода используется комбинация stty и read. Для хранения состояния игрового поля используется массив в памяти. Временные файлы используются только для построения вывода.

Управление осуществляется стрелками или клавишами WASD для движения. Клавиша Q - выход из игры. Есть 7 классических фигур тетриса, каждая со своим цветом, отображается следующая фигура для планирования ходов.

Система очков: 100 очков за 1 линию, 300 за 2, 500 за 3, 800 за 4 (умножается на уровень). Уровень увеличивается каждые 10 очищенных линий, скорость падения растет с уровнем.

При нажатии латинской буквы P текущий уровень растет на 1, увеличивается скорость игры.

Игра тестировалась на wsl Ubuntu 24.04.2
